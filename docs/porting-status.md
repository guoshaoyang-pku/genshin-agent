# 当前可用范围

核心无窗口输入已解决。完整 BetterGI 功能迁移尚未结束。以下状态分别表示实机通过、已有实现且离线测试通过、以及尚无对应后端。

| 功能 | 当前状态 | 使用边界 |
| --- | --- | --- |
| 无窗口截图、键盘与视角 | 实机通过 | 复用原版云输入 SDK。无需窗口前置或指针锁。 |
| 主界面与菜单往返 | 实机通过 | 已验证 Esc 菜单及返回游戏。 |
| 原版 JavaScript 脚本宿主 | 单包实机通过 | 「取消任务追踪」v1.0 通过。其他脚本按依赖逐个验证。 |
| 背包材料统计 | 单材料实机通过 | 使用原版模型及文字识别。其他材料仍需单项验收。 |
| 地图定位、朝向识别 | 实机通过 | 完整传送和采集路线尚待端到端验收。 |
| 路线导航、采集动作、队伍与技能识别 | 已实现，离线通过 | 复用原版路线、地图和动作定义。角色、传送点及路线前置条件必须满足。 |
| 邮件、历练点、纪行、派遣与调整时间 | 已实现，待完整实测 | 部分菜单有早期操作记录，不据此声明全部日常可靠。 |
| 拾取、吃药、跳剧情与实时任务 | 已实现，离线通过 | 自动跳剧情的音频语音检测未接入。 |
| 文本/JSON 战斗脚本与自动连招 | 已实现，离线通过 | 保留原版解析和行为树语义。真实战斗尚待验收。 |
| Boss、秘境、树脂与奖励识别 | 已实现，离线通过 | 完整战斗、领奖及消耗树脂流程尚待验收。 |

| 原生地脉、幽境与一条龙配置分发 | 尚未接通 | 原版集合已有相关脚本，下一步继续对照接口复用。 |
| 自动角色养成规划 | 尚未接通 | 网页生成材料需求，宿主的养成后端尚未实现。 |
| 快速购买、锻造、尘歌壶、开宝箱与兑换码 | 尚未接通 | 需继续对照原版脚本和接口迁移。 |
| 桌面录制、系统热键、画中画与外部 Shell | 尚未接通 | 属于原版桌面能力，云浏览器环境没有对应实现。 |

已固定的上游资源包含 144 个活跃 JavaScript 包和 5,308 条路线。这是资源盘点，不是通过实机验证的功能数量。固定版本及逐文件哈希由资源安装程序记录。

原版导出的部分 .NET 类型、OpenCvSharp 成员和正则表达式方言仍不完全等价。遇到缺失接口时应返回具体错误，不能以空结果冒充成功。

## 验证方式

验收摘要见 [validation.json](validation.json)。公开摘要不包含游戏账号、截图、登录态或私人路径。离线回归可由安装资源后的新克隆运行，实机验收需要本人登录并在安全空地执行 `scripts/bettergi/validate-live.mjs`。

哥伦比娅材料计划供选择目标和计算库存缺口。路线目录存在只说明有原版资源，不保证该路线已在当前云游戏、队伍或地图状态下通过。
