# Third-party sources and attribution

This workspace adapts BetterGI task logic to Node/Python and the cloud-game runtime. Run `node scripts/bettergi/fetch-resources.mjs` to restore original files under `third_party/bettergi`; imported paths, revisions, byte counts and SHA256 values are recorded in `third_party/bettergi/provenance.json`. The public repository distributes adapters and tests, not the upstream script collection or large models. Local adapters do not imply that every upstream feature or script is operational.
